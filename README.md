# الموقع المساند لمقرر تقنية تصميم صفحات الويب 1266

الموقع ثابت، باللغة العربية واتجاه RTL. ينشر من جذر المستودع عبر GitHub Pages. لا يحتاج تثبيت حزم أو عملية بناء.

## التجربة الحالية
- خمس وحدات ضمن قالب موحد و59 درساً، مع تنقل بين الدروس وروابط مباشرة لكل درس.
- 90 مثالاً متصلاً بمختبر HTML وCSS وJavaScript، تشمل أمثلة حلول المختبر.
- بحث داخل الدروس وتطبيقات المختبر، يعرض رابط الدرس المطابق.
- حفظ الإنجاز وآخر درس ومسودة المختبر محلياً في متصفح الطالب دون حساب.
- معاينة معزولة للكود، مع إظهار alert وconsole.log والأخطاء واستقبال قيم prompt بالترتيب.
- تفسير إجابات التقويم، ودليل إعداد PHP وMySQL مع ملفي hello.php وcheck-db.php.
- مشروع الأنشطة الطلابية عبر مراحل HTML/CSS ثم JavaScript ثم DOM والحفظ المحلي ثم PHP/MySQL.
- بطاقات مشاريع ختامية بمهارات ومتطلبات واضحة، وتفاصيل بروابط مباشرة.
- لا توجد روابط تنزيل للكتاب.

## الملفات
index.html للرئيسية، units/ للدروس، lab.html للمختبر، journey.html للمشروع المتدرج، setup.html للإعداد، practical.html للمشاريع.
assets/css/learning.css هو قالب التصميم المشترك. assets/js/learning.js يدير التنقل والبحث والحفظ والمختبر.
examples.json يحمل الكود الأصلي ونوعه ورابط مصدره. search-index.json يحمل عناوين الدروس ونصوص البحث وروابطها.
downloads/ يحتوي الحزم التدريبية. PHP داخل الحزم يعمل محلياً؛ GitHub Pages لا ينفذه.

## التحرير
عدّل الصفحات وملفي البيانات مباشرة، وحافظ على معرفات الدروس والأمثلة حتى تبقى الروابط المحفوظة صالحة.
لا تعِد تشغيل أدوات الإنشاء القديمة عشوائياً؛ هي لخطوات التحويل السابقة وقد تستبدل التحريرات الحالية.
المحتوى الأساسي يبقى متاحاً مع تعطيل JavaScript، بما فيه الدروس وروابط التنقل. البحث والمختبر والحفظ تحتاج JavaScript.

## التحقق المنجز
- فحص الملفات والروابط ومعرفات الدروس والأمثلة، وعدم وجود روابط للكتاب.
- فحص JavaScript وPHP، وتجربة HTML وprompt/alert في المختبر.
- تجربة البحث والإنجاز والتنقل والتقويم وشرح الإجابات، وإبقاء تطبيقات GUI فعالة.
- عرض صفحات أساسية ضمن إطار 390 بكسلاً (مساحة محتوى فعلية 375 بكسلاً مع شريط التمرير): دون تجاوز عرض الصفحة.
- فحص مستقل لسجل أخطاء الوحدة الرابعة بعد التنظيف: خالٍ من أخطاء التشغيل في المسارات المختبرة.
- فحص إضافة الأنشطة وتعديلها وحذفها وحدود المقاعد وترميز العرض وCSRF باستخدام PHP 8.4 ومحوّل SQLite مؤقت خارج الموقع.
- لم يُختبر الاتصال الفعلي بـMySQL لعدم توفر خادم MySQL في بيئة العمل. ملفات التسليم تستخدم PDO/MySQL كما هو موضح في دليل الإعداد.

## التحقق المحلي
أداة tools/verify_site.py تفحص الروابط ومعرفات الأمثلة. تحتاج Python وBeautifulSoup4. لا ترفع أدوات الاختبار أو ملفات المعاينة الداخلية إلى الموقع.

## التحسين البصري اللاحق
- مقدمة مختصرة مع بحث جانبي، ومسار رأسي مرقّم للوحدات الخمس بدلاً من شبكة تترك وحدة منفردة.
- خط Cairo بأوزان 400 و600 و700، مخزّن محلياً في assets/fonts. ترخيصه في OFL.txt.
- عزل المصطلحات والعبارات الإنجليزية داخل النص العربي باستخدام bdi.
- فهرس مختصر بترقيم واحد، وأولوية زر جرّب المثال على النسخ.
- تلوين HTML وCSS وJavaScript وPHP وSQL باستخدام نسخة Prism 1.30.0 محلية، وترخيصها في assets/vendor/PRISM-LICENSE.txt.
- فحص العرض الضيق في 9 صفحات، وصحة وضع HTML القياسي، وتلوين الأكواد، وعدم ظهور أخطاء في مسار الدرس المختبر.
