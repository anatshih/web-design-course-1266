# الموقع المساند لمقرر 1266

النسخة توسّع الموقع القائم إلى الوحدات الخمس وفق ترتيب المادة:
1. المفاهيم الأساسية لتقنية الإنترنت والويب.
2. HTML وتصميم المواقع وCSS.
3. برمجة المخدوم باستخدام JavaScript.
4. تصميم صفحات الويب الديناميكية باستخدام JavaScript.
5. برمجة المواقع بلغة PHP وSQL.

## المعاينة
افتح index.html، أو شغّل خادم ملفات محلي وافتح الموقع عبر localhost. لا يحتاج الموقع إلى بناء أو حزم خارجية. تعمل الصفحات الجديدة دون خطوط أو مكتبات خارجية؛ الصفحات القديمة تحتفظ بمصادرها الأصلية.

## المحتوى
- استكمال صفحتي الوحدة الأولى والخامسة اللتين كانتا فارغتين.
- الحفاظ على محتوى الوحدات الثانية والثالثة والرابعة والمشروع العملي.
- تصحيح أوصاف الوحدات وروابط العودة والتنزيل.
- إضافة بحث عن الوحدات وتنقل مشترك ومختبر HTML/CSS/JavaScript.
- إضافة ملفات PDF للوحدات الخمس من المادة التعليمية.
- حزمة PHP/SQL مع تعليمات عربية: downloads/unit5/php-sql-lab.zip.

## النشر
الملفات الثابتة جاهزة لنشرها في جذر مستودع GitHub Pages القائم. لا تشغّل GitHub Pages ملفات PHP؛ تبقى حزمة PHP للتنزيل والتشغيل المحلي.

## التحقق المنجز
- فحص جميع روابط الملفات المحلية: لا روابط مفقودة.
- تجربة البحث وتحليل URL والتقويم في المتصفح.
- تشغيل JavaScript في المختبر وتعديل الكود واستعادة المثال.
- مراجعة مرئية للصفحة الرئيسية والوحدة الخامسة.
- فحص بناء JavaScript وصياغة PHP 8.4.
- اختبار مسارات الإضافة والتعديل والحذف ورفض العلامة غير الصالحة ورفض CSRF وعرض HTML كنص باستخدام PHP 8.4 ومحوّل قاعدة SQLite مؤقت خارج المشروع.
- لم يُختبر الربط الفعلي بـMySQL؛ يحتاج إلى خادم MySQL/بيئة XAMPP لدى المشغّل. بقيت ملفات المشروع المرفقة مهيأة لـMySQL عبر PDO.

## تحرير المحتوى
يمكن تعديل HTML مباشرة. أدوات Python في tools تعيد إنشاء الصفحات الجديدة وتجميع ملفات المادة؛ لا تشغّلها بعد تعديل يدوي دون تحديث نصوص التوليد أيضاً.
