1. خطة العمل وبيئة التشغيل

ابدأ بدليل إعداد PHP و MySQL

تتعلم في هذه الوحدة أساسيات PHP والمتغيرات والعوامل وبنى التحكم والدوال، ثم SQL وربط PHP بقاعدة MySQL وتنفيذ الإضافة والعرض والتعديل والحذف.

أكواد PHP و SQL هنا أمثلة للتشغيل على جهازك. GitHub Pages لا يشغل PHP ولا يوفر قاعدة MySQL. معاينة HTML في المختبر لا تنفذ PHP.

  1. جهّز بيئة محلية تحتوي PHP و MySQL أو MariaDB وخادم ويب، مثل XAMPP، وشغّل خدمتي الويب وقاعدة البيانات.
  2. ضع مجلد التدريب في مجلد الويب المحلي، مثل htdocs في XAMPP.
  3. افتح http://localhost/course/ بدلاً من فتح ملف PHP بالنقر المزدوج.
  4. استخدم أداة إدارة القاعدة المتاحة لديك لاستيراد schema.sql.

الملفات المرفقة تستهدف PHP 8 مع امتداد pdo_mysql. إذا اختلف منفذ الخادم فأضفه إلى العنوان. لا تحتاج إلى استضافة مدفوعة لإتمام التدريب.

2. العميل والخادم والبرنامج الأول

JavaScript في أمثلة الوحدتين السابقتين يعمل في المتصفح. PHP يعمل في الخادم ويرسل النتيجة إلى المتصفح. لن يظهر كود PHP في مصدر الصفحة الناتجة إذا كانت بيئة الخادم تعمل بصورة صحيحة.

احفظ المثال باسم hello.php وافتحه عبر localhost. النتيجة المتوقعة عنوان وفقرة بالعربية.

<?php
$course = "تقنية تصميم صفحات الويب";
?>
<!doctype html>
<html lang="ar" dir="rtl">
<meta charset="utf-8">
<title>أول برنامج PHP</title>
<h1>مرحباً بالطلبة</h1>
<p><?= htmlspecialchars($course, ENT_QUOTES, "UTF-8") ?></p>
</html>

غيّر اسم المقرر. ماذا يشاهد المتصفح؟

3. المتغيرات والأنواع والثوابت

تبدأ أسماء المتغيرات بالرمز $ وتراعي حالة الأحرف. الأنواع البسيطة تشمل العدد الصحيح والعشري والنص والمنطقي. المصفوفات تجمع قيماً، والكائنات تمثل بيانات وسلوكاً، وNULL يعني غياب القيمة، وresource يمثل مورداً مثل مقبض ملف.

4. التعابير والعوامل

التعبير ينتج قيمة. من العوامل الحسابية + و- و* و/ و%، والإسناد = و+=، والمقارنة === و!== و>=، والمنطقية && و|| و!، والربط النصي نقطة. الأقواس توضح ترتيب التنفيذ.

<?php
$total = 20 + 5 * 2;     // 30
$grouped = (20 + 5) * 2; // 50
$mark = 70;
$passed = $mark >= 50 && $mark <= 100;
echo "المجموع: " . $total;
var_dump(5 === "5");   // false
عوامل إضافية يوردها الكتاب

++ و-- للزيادة والنقصان، و& و| و^ و<< و>> لعمليات البت. يجمع + مصفوفتين مع الاحتفاظ بمفاتيح اليسرى. instanceof يفحص نوع كائن. يورد الكتاب @ للتحكم برسائل الخطأ وbackticks لتنفيذ أوامر نظام؛ افهم دورهما ولا تستخدمهما لإخفاء أخطاء التطبيق أو لتنفيذ إدخال المستخدم. نستخدم الاستثناءات لمعالجة أخطاء القاعدة.

5. الشروط والحلقات وبنى التحكم

استخدم if وelseif وelse لاتخاذ قرار، وswitch للاختيار بين حالات. while يفحص الشرط قبل التكرار، وdo…while ينفذ مرة على الأقل، وfor مناسب لعدد معلوم، وforeach لمرور عناصر المصفوفة.

<?php
$marks = [40, 75, 90];
foreach ($marks as $mark) {
    if ($mark >= 50) {
        echo "ناجح: $mark<br>";
    } else {
        echo "بحاجة إلى مراجعة: $mark<br>";
    }
}
for ($i = 1; $i <= 3; $i++) {
    echo $i . " ";
}

break يوقف الحلقة أو switch، وcontinue يتجاوز بقية التكرار الحالي. return يعيد نتيجة الدالة وينهيها. declare يحدد توجيهات تنفيذ مثل strict_types. يورد الكتاب goto والصياغة البديلة if: … endif؛ في التطبيقات هنا نستخدم بنى واضحة دون القفز بين السطور.

طبّق بنفسك

اطبع الأعداد الزوجية من 2 إلى 10 باستخدام for.

الحل المقترح
<?php
for ($i = 2; $i <= 10; $i += 2) {
    echo $i . " ";
}

6. الدوال وتقسيم الملفات

الدالة تجمع مهمة قابلة لإعادة الاستخدام. المعاملات مدخلات، وreturn يعيد الناتج. توجد دوال مضمّنة وأخرى تعرفها بنفسك، ويمكن إسناد دالة مجهولة إلى متغير أو استدعاء دالة باسم محفوظ في متغير.

<?php
function average(array $marks): float {
    if (count($marks) === 0) {
        return 0;
    }
    return array_sum($marks) / count($marks);
}
echo average([70, 80, 90]); // 80
$double = function ($value) { return $value * 2; };
echo $double(4); // 8

include وrequire يضمان ملفاً آخر؛ فشل require يوقف التنفيذ عادة، بينما include يصدر تحذيراً ويمكن أن يستمر. الصيغتان include_once وrequire_once تمنعان تكرار التضمين. استخدم مساراً ثابتاً مثل require_once __DIR__ . "/db.php"، ولا تأخذ مسار الملف من الزائر.

طبّق بنفسك

اكتب دالة تعيد ناجح إذا كانت العلامة 50 فأكثر.

الحل المقترح
<?php
function result(int $mark): string {
    return $mark >= 50 ? "ناجح" : "راسب";
}
echo result(65);

7. استقبال بيانات النماذج

يرسل GET قيماً في العنوان، وPOST يرسلها في جسم الطلب. POST وحده لا يشفر البيانات. تحقق في الخادم حتى إذا أضفت تحققاً في JavaScript. htmlspecialchars يعالج النص عند عرضه داخل HTML؛ ولا يحل محل الاستعلامات المحضرة.

<!-- form.html -->
<form action="welcome.php" method="post">
  <label>الاسم <input name="name" required maxlength="100"></label>
  <button>إرسال</button>
</form>

<!-- welcome.php -->
<?php
$raw = $_POST["name"] ?? "";
$name = is_string($raw) ? trim($raw) : "";
if ($name === "" || strlen($name) > 400) {
    http_response_code(422);
    exit("أدخل اسماً صالحاً");
}
echo "مرحباً " . htmlspecialchars($name, ENT_QUOTES, "UTF-8");

8. SQL: إنشاء قاعدة وجدول

قاعدة البيانات تحتوي جداول، والجدول يتكون من صفوف وأعمدة. المفتاح الأساسي يميز السجل، وAUTO_INCREMENT ينشئ معرفاً متزايداً. اختر utf8mb4 لدعم العربية.

CREATE DATABASE IF NOT EXISTS course1266
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE course1266;
CREATE TABLE IF NOT EXISTS students (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  mark INT NOT NULL
);

نفذ الأوامر في أداة إدارة MySQL. DROP TABLE يحذف الجدول، وDROP DATABASE يحذف القاعدة ومحتوياتها؛ لا تحتاج إلى تشغيلهما لإتمام المختبر.

طبّق بنفسك

لماذا لا نستخدم اسم الطالب مفتاحاً أساسياً؟

الحل المقترح

قد تتكرر الأسماء أو تتغير. المعرف الرقمي يوفر قيمة مستقلة تميز كل سجل.

9. SQL: الإضافة والاستعلام والتعديل والحذف

ابدأ بقاعدة تدريب فقط. WHERE يحدد السجلات المستهدفة؛ غيابه في UPDATE أو DELETE يؤثر في كل السجلات. ORDER BY يرتب النتائج، وLIMIT يحدد عددها.

INSERT INTO students (name, mark) VALUES ('ليان', 85), ('عمر', 70);
SELECT id, name, mark FROM students ORDER BY id;
SELECT name, mark FROM students WHERE mark >= 80 ORDER BY mark DESC LIMIT 5;
UPDATE students SET mark = 90 WHERE id = 1;
DELETE FROM students WHERE id = 2;

طبّق بنفسك

اعرض الطلاب الناجحين مرتبين حسب العلامة تنازلياً.

الحل المقترح
SELECT id, name, mark FROM students
WHERE mark >= 50 ORDER BY mark DESC, id ASC;

10. ربط PHP بقاعدة MySQL

PDO وMySQLi طريقتان للربط. MySQLi مخصص لـMySQL، بينما PDO يوفر واجهة تتعامل مع عدة محركات عبر برامج تشغيل مختلفة. نستخدم PDO واستعلامات محضرة لتمرير القيم منفصلة عن نص SQL.

<?php
// db.php - بيانات بيئتك المحلية
$pdo = new PDO(
    "mysql:host=127.0.0.1;dbname=course1266;charset=utf8mb4",
    "course_student",
    "change-this-local-password",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
     PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
     PDO::ATTR_EMULATE_PREPARES => false]
);
<?php
require_once __DIR__ . "/db.php";
$stmt = $pdo->prepare("INSERT INTO students (name, mark) VALUES (:name, :mark)");
$stmt->execute(["name" => "ليان", "mark" => 85]);
$query = $pdo->prepare("SELECT id, name, mark FROM students WHERE mark >= ? ORDER BY id LIMIT 10");
$query->execute([50]);
foreach ($query as $student) {
    echo htmlspecialchars($student["name"], ENT_QUOTES, "UTF-8") . "<br>";
}

أنشئ مستخدم قاعدة محلياً يملك صلاحيات SELECT وINSERT وUPDATE وDELETE على قاعدة التدريب، ثم عدّل db.php. تشرح تعليمات المشروع ذلك. إذا فشل الاتصال، تحقق من تشغيل الخدمة واسم القاعدة والمنفذ وبيانات المستخدم وامتداد pdo_mysql.

11. المشروع التطبيقي: سجل الطلبة

حزمة المختبر تحتوي schema.sql وdb.php وindex.php ودليل تشغيل عربي. تنفذ إضافة طالب وعرض السجلات وتعديل العلامة والحذف. يستخدم المشروع جلسة ورمز CSRF مع طلبات POST، ويتحقق من الاسم والعلامة في الخادم.

تحميل الحزمة
  1. استورد schema.sql وأنشئ مستخدم قاعدة التدريب.
  2. اضبط بيانات الاتصال في db.php.
  3. افتح المشروع من localhost وأضف طالباً بعلامة 85.
  4. عدّل العلامة إلى 90 ثم أعد تحميل الصفحة للتأكد من حفظها.
  5. جرّب إدخال علامة 120 واسماً فارغاً؛ يجب رفضهما.
  6. احذف سجلاً تجريبياً وتأكد من اختفائه.

معايير النجاح: استمرار البيانات بعد إعادة التحميل، رفض القيم غير الصالحة، عرض العربية سليمة، وعدم تأثر السجلات الأخرى عند التعديل أو الحذف.

التوسعة المقترحة

أضف بحثاً بالاسم باستخدام LIKE ومعامل محضر، ثم أضف ترتيباً ثابتاً وتقسيماً للنتائج. هذه حزمة تدريب محلي، وليست نظام شؤون طلبة جاهزاً للنشر العام.
