# مختبر PHP وSQL — الوحدة الخامسة

هذا تطبيق محلي للتدريب، وليس خدمة منشورة للطلبة. استخدم بيانات وهمية فقط.

## المتطلبات
PHP 8 مع pdo_mysql، وMySQL أو MariaDB. يمكن استعمال XAMPP.

## التشغيل
1. فك الضغط داخل مجلد باسم course في مجلد خادم الويب المحلي (مثلاً htdocs).
2. شغل Apache وخدمة MySQL في بيئتك.
3. افتح أداة إدارة MySQL مثل phpMyAdmin واستورد schema.sql بحساب يملك صلاحية إنشاء القاعدة.
4. أنشئ مستخدماً محلياً مخصصاً للتدريب. يمكنك تنفيذ ما يلي بحساب إدارة القاعدة:

```sql
CREATE USER 'course_student'@'127.0.0.1' IDENTIFIED BY 'change-this-local-password';
GRANT SELECT, INSERT, UPDATE, DELETE ON course1266.* TO 'course_student'@'127.0.0.1';
```

اختر كلمة مرور محلية وعدّلها في db.php أيضاً. إذا كان المستخدم موجوداً استخدمه أو حدّث إعداداته بدلاً من إعادة CREATE USER.
5. عدّل db.php بما يطابق اسم المضيف والقاعدة والمستخدم وكلمة المرور. إذا اختلف منفذ MySQL أضف port إلى DSN.
6. افتح http://localhost/course/index.php. إذا اختلف منفذ Apache فاستخدمه في العنوان.

## التحقق
- أضف ليان بعلامة 85، ثم أعد تحميل الصفحة: يجب بقاء السجل.
- عدّل العلامة إلى 90 ثم تحقق من بقائها بعد إعادة التحميل.
- جرّب علامة 120 و-1 ونصاً واسماً فارغاً: يجب رفضها، حتى عند تجاوز تحقق المتصفح.
- أدخل نصاً مثل <b>طالب</b>: يجب عرضه كنص لا كوسم HTML.
- احذف سجلاً تجريبياً من منطقة تأكيد الحذف؛ تحقق من بقاء بقية السجلات.
- يعرض التطبيق آخر 100 سجل فقط؛ أضف تقسيماً للصفحات كتدريب إضافي.

## تشخيص المشكلات
- ظهور كود PHP: افتح الصفحة عبر localhost وتحقق من تشغيل PHP.
- could not find driver: فعّل pdo_mysql وأعد تشغيل الخادم.
- تعذر الاتصال: تحقق من تشغيل MySQL واسم القاعدة والمنفذ وصلاحيات المستخدم.
- تفاصيل أخطاء PDO تسجل في سجل الخادم ولا تعرض للزائر.
- لا ترفع ملفات PHP هذه إلى GitHub Pages متوقعاً تشغيلها؛ نزّل الحزمة وشغّلها محلياً.

## فهم الملفات
schema.sql ينشئ القاعدة والجدول دون حذف البيانات القائمة. db.php ينشئ الاتصال.
index.php ينفذ POST ثم يعيد التوجيه لتفادي تكرار الإضافة عند إعادة التحميل، ويفصل المدخلات عن SQL باستعلامات محضرة، ويتحقق من رمز CSRF ومن قيم الحقول.
لا توجد حسابات دخول أو صلاحيات مستخدمين في هذا التدريب المحلي؛ إضافتها لازمة قبل تحويله إلى نظام عام.
